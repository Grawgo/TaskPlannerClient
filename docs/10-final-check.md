# Состояние проекта — 03.10.2026

## Выбранная конфигурация

Android-клиент открывается в Android Studio, Ktor-сервер — в IntelliJ IDEA.
PostgreSQL находится на ноутбуке. Телефон и ноутбук работают в одной Wi-Fi
сети. Телефон обнаруживает сервер автоматически; USB и ввод IP не нужны.
Firebase используется только для входа и регистрации, задачи — в PostgreSQL.
Интернет нужен для Firebase и загрузки открытых сертификатов Google.

Материалы задания содержат локальный и удалённый варианты размещения БД.
Текущая реализация использует локальный вариант.

## Проверенные требования

- Kotlin на клиенте и сервере, Ktor REST API и PostgreSQL.
- Jetpack Compose, Material 3, Navigation Compose, Hilt.
- Слои data, domain и presentation; Retrofit, Room для истории поиска.
- Email/password через Firebase Authentication, сохранение сессии и выход.
- Задачи не сохраняются в Firestore или Realtime Database.
- Создание, просмотр, редактирование, удаление, статусы, приоритеты и сроки.
- Список и поиск загружают все страницы; фильтр по приоритету доступен в UI.
- История до 10 запросов, разделённая по UID; очистка и сохранение текста при повороте.
- Загрузка, пустые состояния, ошибки, повтор запросов, светлая и тёмная темы.
- Проверка подписи токенов и ограничения доступа владельцем на сервере.
- Сборки клиента и сервера, 15 модульных тестов клиента, 9 тестов сервера,
  4 инструментальных теста Android и Android Lint без ошибок.
- Реальные Firebase-аккаунты: регистрация и вход через API, CRUD и изоляция двух пользователей.
- Запуск Ktor с локальной БД, обнаружение и HTTP-доступ по Wi-Fi адресу.
- Локальные файлы конфигурации исключены из Git.

Подробные результаты и границы проверок: [протокол тестирования](09-testing.md).

## Условия запуска

- PostgreSQL работает на ноутбуке.
- TaskPlannerServer запускается в IntelliJ IDEA с JDK 21 через
  `application → run`; рабочий каталог — корень проекта.
- Локальный `.env` содержит `SERVER_HOST=0.0.0.0`, настройки PostgreSQL
  и `FIREBASE_PROJECT_ID`.
- Успешная проверка `http://127.0.0.1:8080/v1/health` возвращает
  `{"status":"ok"}`.
- Телефон с актуальным APK находится в той же Wi-Fi сети.
- В macOS доступны входящие подключения Java. Сеть с изоляцией клиентов
  не поддерживает обнаружение сервера.

HTTP используется для учебной демонстрации в доверенной локальной сети.
Публичное размещение сервера не входит в выбранную конфигурацию.
