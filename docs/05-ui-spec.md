# Макет интерфейса

Исходный размер каждого макета — 390 × 844 dp. Файлы PNG находятся в
`mockups/`; обзор всех экранов — `mockups/overview.png`. Они фиксируют
компоновку для последующей реализации на Jetpack Compose.

## Визуальная система

| Элемент | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | `#F7F7FB` | `#15141B` |
| Поверхность карточек | `#FFFFFF` | `#24232B` |
| Основной текст | `#1C1B22` | `#F4F2F8` |
| Вторичный текст | `#6F6D79` | `#B5B2C0` |
| Основной цвет | `#6856A8` | `#B8A7F0` |
| Ошибка/просрочка | `#B72D3A` | `#FFB4BD` |

Шрифт в макетах — Arial как доступный системный заменитель. В Android
используется системный sans-serif с аналогичными размерами. Базовая сетка
8 dp, горизонтальные отступы 20–24 dp, скругление карточек 20 dp,
полей 16 dp, кнопок 18 dp. Высота основных кнопок — 52 dp.

## Экраны

| Файл | Содержимое | Основные действия |
|---|---|---|
| `01-login.png` | Вход, email, пароль | Войти, перейти к регистрации |
| `02-register.png` | Регистрация, подтверждение пароля | Создать аккаунт, вернуться |
| `03-task-list.png` | Список, фильтр статуса, карточки | Поиск, открыть/завершить задачу, создать |
| `04-search-history.png` | Пустое поле и история | Выбрать запрос, очистить историю |
| `05-search-results.png` | Результаты поиска | Очистить поле, открыть результат |
| `06-search-empty.png` | Нет совпадений | Изменить запрос |
| `07-search-error.png` | Ошибка запроса | Обновить, повторив запрос |
| `08-task-detail.png` | Полная задача | Изменить, удалить, отметить выполнение |
| `09-task-editor.png` | Форма задачи | Сохранить, выбрать дату/приоритет/статус |
| `10-settings.png` | Аккаунт и оформление | Переключить тему, выйти |
| `11-task-list-dark.png` | Тёмный вариант списка | Проверка цветовой схемы |
| `12-task-list-empty.png` | Нет созданных задач | Создать первую задачу |
| `13-search-loading.png` | Запрос выполняется | Индикатор загрузки |

При нажатии на поисковую строку открывается экран истории или результатов.
Кнопка «Очистить» появляется только при непустом вводе; после нажатия
текст исчезает, клавиатура закрывается. При повороте экрана запрос
восстанавливается. Состояния загрузки и ошибки располагаются в области
результатов без смены экрана. Кнопка «Обновить» повторяет последний
запрос. Нажатие на результат открывает детали и добавляет запрос в
историю. При возврате из деталей результат и введённый текст сохраняются.

Карточка содержит название, короткое описание, срок, приоритет и статус.
Просроченная незавершённая задача выделяется цветом ошибки. На форме
ошибка валидации выводится под соответствующим полем, а «Сохранить»
остаётся доступной для повторной попытки после исправления.

## Обязательные состояния для реализации

Загрузка списка, пустой список задач, пустая история, загрузка поиска,
пустой результат поиска, ошибка поиска, ошибка сохранения задачи,
недействительная сессия, светлая и тёмная темы. Это состояния экранов,
поэтому для каждого не требуется отдельный маршрут навигации.
