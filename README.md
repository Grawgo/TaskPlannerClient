# Планировщик задач — Android-клиент

Android-приложение для управления личными задачами. Интерфейс реализован
на Jetpack Compose с Material 3. Архитектура разделена на слои `data`,
`domain` и `presentation`. В проекте используются Navigation Compose,
Hilt, Retrofit, Room и DataStore.

## Возможности

- Регистрация, вход, восстановление пароля и сохранение сессии через Firebase Authentication.
- Создание, просмотр, редактирование и удаление задач.
- Сроки, приоритеты и статусы выполнения.
- Фильтрация по статусу и приоритету, сортировка по сроку или изменению.
- Поиск по названию и описанию с локальной историей запросов.
- Светлая и тёмная темы с сохранением выбора.

Задачи сохраняются в PostgreSQL через отдельный Ktor-сервер
`TaskPlannerServer`. Room хранит историю поиска, DataStore — настройку темы.

## Окружение и сборка

| Компонент | Требование |
|---|---|
| Среда разработки | Android Studio |
| JDK | 17 или новее |
| Android SDK | API 35 |
| Минимальная версия Android | API 23 |

Путь к Android SDK задаётся в локальном `local.properties`. Этот файл
исключён из Git.

Сборка отладочного APK:

```bash
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Подключение к серверу

Ktor и PostgreSQL работают на ноутбуке. Физический телефон подключается
к той же Wi-Fi сети и автоматически обнаруживает сервер по UDP-порту
`45678`. HTTP-запросы отправляются на обнаруженный адрес и порт сервера
(по умолчанию `8080`). USB и ручной ввод IP-адреса не требуются.

Для обнаружения сервер использует `SERVER_HOST=0.0.0.0`. Android Emulator
обращается к нему по адресу `http://10.0.2.2:8080/`.

Локальное подключение работает в сети без изоляции устройств, при
доступных UDP-порте `45678` и TCP-порте сервера. Вне этой сети Ktor
недоступен. Firebase Authentication использует интернет-соединение.

## Аутентификация

Firebase Authentication используется для учётных записей и выдачи
ID-токенов. Firestore и Realtime Database не используются. Сессия на
устройстве зашифрована; пароль пользователя не сохраняется.

Web API key Firebase задаётся в локальном `firebase.properties` по образцу
`firebase.properties.example`. Идентификатор того же Firebase-проекта
задаётся в конфигурации Ktor. Файл с ключом исключён из Git. Без ключа
приложение собирается, но операции аутентификации недоступны.

Конфигурация описана в [документации Firebase](docs/08-firebase-setup.md).

## Проверки

Модульные тесты:

```bash
./gradlew :app:testDebugUnitTest
```

Инструментальные тесты при запущенном эмуляторе или подключённом устройстве:

```bash
./gradlew :app:connectedDebugAndroidTest
```

Статический анализ:

```bash
./gradlew :app:lintDebug
```
